# ColorMatrix

**This repository is deprecated and unmaintained.**

The Rec.2020 support added in v2.6 (2018) is incorrect: I added it without knowing that color primaries are a separate property from the matrix, so conversions to or from Rec.2020 do not produce correct results.

Please use the corrected fork instead:

- [BlohoJo/ColorMatrixCorrected](https://github.com/BlohoJo/ColorMatrixCorrected)

No further commits or releases will be made here.
